# Baigan Ji — Waffle Date ❤️

GitHub Pages-ready static website.

## Upload
Upload these to the root of your repository:
- `index.html`
- `style.css`
- `script.js`
- `assets/baigan-meme.jpg`
- `assets/this-could-be-us.jpg`
- `assets/song.mp3`

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

The site has no backend and needs no build step.

### Audio note
Browsers commonly block autoplay. This site starts the uploaded song after the first user interaction (the Tap here button), so it works with normal browser autoplay rules.
